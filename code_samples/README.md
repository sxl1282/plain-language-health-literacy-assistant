# 代码阅读指南

这些片段来自健康素养子模块的原型实现，用于核对产品方案与关键处理逻辑。建议按下列顺序阅读。

| 顺序 | 样例 | 关注点 |
| --- | --- | --- |
| 1 | [术语识别与检索](simplifier.py) | 词库选择、词边界、长短语优先、重叠消解和术语去重。 |
| 2 | [知识上下文与生成约束](grounded_rewrite_excerpt.py) | 如何把检索解释写入 Prompt，以及如何约束无依据扩展。 |
| 3 | [生成风险检查](faithfulness_check_excerpt.py) | 比较原文与生成文本中的高风险表述，输出供人工复核的提示。 |
| 4 | [流程编排](pipeline.py) | 解释、溯源、规则结果、可选生成及错误状态如何衔接。 |
| 5 | [隐私处理](privacy.py) | 对常见姓名、联系方式与标识等内容做尽力而为的遮蔽。 |
| 6 | [界面呈现](streamlit_ui_excerpt.py) | 原文高亮、解释与来源句卡片、就诊问题的展示方式。 |

## 公开范围

- 流程样例中的 `src.*` 指向完整项目的内部模块；术语识别中的 `data.processed.*` 指向未随本展示版提供的知识库。
- 生成片段保留上下文构造与 Prompt，省略模型服务调用及部署配置。
- 界面片段保留代表性函数与对应高度常量，省略完整页面入口。
- 样例省略命令行演示，保留核心处理函数；本仓库按代码阅读用途组织，未提供完整应用启动命令。
- 规则风险检查不输出项目的准确率或平均忠实度评分；这些项目结果统一见 [README](../README.md#项目成果)。

需求到实现的对应关系见 [产品规划](../docs/product-planning.md) 和 [RAG 方案](../docs/rag-design.md)。
