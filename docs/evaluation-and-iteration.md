# AI 治理｜Baseline、Bad Case 与效果迭代

## 项目结果

| 指标 | 迭代前 | 迭代后 |
| --- | ---: | ---: |
| 术语识别准确率 | 88% | **93%** |
| 生成摘要的平均忠实度评分 | 80% | **87%** |

两组指标分别描述术语识别质量与生成信息忠实度。逐条标注记录和评分明细不在本精选仓库中公开；规则检查中的 `pass` / `warning` 是风险提示状态，不等同于上述评分。

## Baseline 的作用

以确定性的术语匹配、解释检索和规则通俗化作为基线，区分检索阶段的问题与生成阶段的信息变化。对比 LLM 输出时，同时关注可读性、信息保留与新增风险。

| 评测层次 | 关注问题 | 归因方向 |
| --- | --- | --- |
| 术语识别 | 专业概念是否被发现，普通词是否被误认为专业术语。 | 词库覆盖、过滤规则、匹配边界与重叠处理。 |
| 知识匹配 | 匹配词、解释与原文来源句是否一致。 | 知识条目、术语歧义、来源句关联。 |
| 生成忠实度 | 是否遗漏、改变或新增原文中的医疗信息。 | Prompt 约束、上下文选择、模型生成。 |
| 文本与交互 | OCR 噪声、长文本及异常是否影响理解或导致流程中断。 | 文本处理、错误提示、降级路径与界面呈现。 |

## Bad Case 分类与迭代措施

下表对应问题类型与已有处理措施，展示归因及优化思路。

| 类型 | 问题表现 | 迭代措施 | 实现 / 复核重点 |
| --- | --- | --- | --- |
| 知识匹配：普通词误识别 | 常见词或状态词触发不适合患者场景的术语解释。 | 过滤不适合展示的词条，保留患者相关解释。 | [词库选择与匹配](../code_samples/simplifier.py)；复核误匹配与新增漏检。 |
| 知识匹配：长短术语重叠 | 如 `CT scan` 与其内部短词被重复解释。 | 长短语优先，按字符区间消除重叠，解释列表去重。 | [extract_medical_terms](../code_samples/simplifier.py)；复核词边界及来源位置。 |
| 文本处理：长文本与 OCR 噪声 | 排版、标点或识别错误干扰术语检索和改写。 | 保留输入核对路径，限制生成上下文，跟踪格式噪声的传播。 | 比较输入、匹配与输出各环节，定位噪声来源。 |
| 模型生成：无依据扩展 | 添加原文未说明的用药变动、检查目的、因果解释或建议。 | 强化只依据原文的约束，增加高风险表述检查。 | [生成约束](../code_samples/grounded_rewrite_excerpt.py)、[风险检查](../code_samples/faithfulness_check_excerpt.py)。 |
| 模型生成：可用性问题 | 生成请求失败或没有可用文本。 | 保留规则输出，区分生成失败与检查未运行。 | [pipeline.py](../code_samples/pipeline.py) 中的失败处理。 |

## 问题追踪闭环

**保留问题输入 → 标记预期与实际差异 → 分层归因 → 明确调整范围 → 回归原问题与相关场景 → 记录剩余限制。**

追踪记录关联输入样例、匹配词、知识解释、生成结果、问题类别、调整措施及复验结论。公开演示使用合成或去标识化材料。

## 治理原则

- 检索依据与生成结果分开展示，保留信息来源。
- 原文、规则 Baseline 与可选生成之间保留核对路径。
- 风险检查用于发现疑点，发现后进入人工复核与整改。
- 就诊准备以问题形式表达待确认内容，避免输出用药和治疗决定。
- 术语识别质量、生成忠实度与临床有效性分别评估。
